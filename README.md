# Commit

Personal organizer for iPhone and Mac. Dark, simple, no fluff.

**Commit** is a pun. In git, a commit is when you save a change and stand behind it. In life, being committed means you follow through. The app is that same move: you write the task down and you commit to doing it — school, errands, all of it.

## What it does

- Folders and workbenches (college vs personal, then subjects or areas)
- Custom sections (exams, assignments, chores — you create them)
- Tasks with title, description, and an optional date
- Month calendar, no time slots
- Date views: today, upcoming, overdue
- Filter by folder or workbench
- Trash (kept 3 days) and completed (kept 4 days)

Data stays on your device. No account, no cloud.
